
# Austin Roof Pros

**🔗 Live Site:** https://guileless-paprenjak-882e0b.netlify.app

### Overview
Live lead-gen website for Austin roofing company. Mobile-first design optimized to capture "roofer near me" searches and convert them to phone calls.

### Key Features
- Click-to-call + SMS integration for instant leads
- FormSubmit automation → sends inquiries straight to owner email 
- Review/testimonial section builds trust
- 100% mobile responsive design
- Deployed on Netlify with custom domain ready

### Tech Stack
HTML5, CSS3, FormSubmit, Netlify

### Result
Live business generating real customer inquiries 24/7. Built and deployed in under 24 hours.
